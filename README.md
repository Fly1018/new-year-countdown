# New Year Countdown

A configurable New Year countdown for SiYuan.

- Opens automatically on the first launch of a configurable period (daily, weekly, once, or never).
- Top-bar clock icon opens the countdown at any time; the badge shows the remaining days.
- Target is the next New Year's Day by default, or a custom date.
- Shows days, an optional hour/minute/second clock, a progress bar, and a snow animation.
- Settings let you choose the target, auto-popup frequency, time display, effects, and badge.
- Settings are stored in plugin storage and mirrored to localStorage.

Rebuilt with Vite 8 + TypeScript + Svelte 5.

## Development

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```
