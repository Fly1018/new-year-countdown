# 新年倒计时

可配置的新年倒计时插件。

- 按设定的频率自动弹出（每天 / 每周 / 仅首次 / 不再自动）。
- 顶栏时钟图标可随时打开倒计时，图标角标显示剩余天数。
- 默认目标是下一个元旦，也可指定自定义日期。
- 显示剩余天数，可选显示时分秒，并带进度条和飘雪动画。
- 设置中可调整目标、自动弹出频率、时间显示、动画和角标。
- 设置保存在插件存储中，并同步到 localStorage。

使用 Vite 8 + TypeScript + Svelte 5 重建。

## 开发

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```
